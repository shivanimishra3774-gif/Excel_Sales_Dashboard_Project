# 📊 ABC Executive Summary & Profitability Dashboard

## 📌 Project Overview

This project is an interactive **Sales Dashboard built using Microsoft Excel** to analyze business performance, revenue, profitability, product categories, sales channels, and regional trends. It provides a clear visual summary of key business metrics to support data-driven decision-making.

## 🎯 Project Objectives

- Analyze total revenue and gross profit.
- Monitor gross profit margin and cost of goods sold (COGS).
- Track monthly revenue and profit trends.
- Compare revenue across different countries.
- Analyze revenue contribution by sales channel and region.
- Explore sales performance using interactive filters.

## 📈 Dashboard Highlights

### Key Performance Indicators (KPIs)

- **Total Revenue:** 645,223.18
- **Total Gross Profit:** 296,384.25
- **Gross Profit Margin:** 45.94%
- **Total Units Sold:** 6,698
- **Total Orders:** 2,707
- **COGS:** 348,838.93

### Visualizations

- **Monthly Revenue & Profit:** Line chart showing monthly revenue and gross profit trends.
- **Top 5 Country Revenue:** Bar chart comparing revenue across leading countries.
- **Revenue Share by Channel:** Pie chart showing revenue contribution from different sales channels.
- **Region-Wise Comparison:** Doughnut chart comparing revenue across regions.
- **Country-Wise Map Chart:** Geographical visualization of revenue distribution.

### Interactive Filters

The dashboard includes slicers for:

- Product Category
- Country
- Quarter (Q1, Q2, Q3, Q4)

These filters allow users to explore sales performance across different categories, countries, and quarters.

1. Download the Excel dashboard file from this repository.
2. Open it in Microsoft Excel.
3. Use the interactive slicers to filter data by product category, country, and quarter.
4. Explore the charts and KPIs to understand sales and profitability trends.
